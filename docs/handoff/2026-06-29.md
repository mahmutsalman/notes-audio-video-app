## Decisions Made
- ADR-0001: Approach A sync protocol in FastAPI. See file.
- Scope: phone writes = media/captions/deletes on EXISTING notes (not append-only; NOT new
  topics/recordings). Single deviceId. Sync stays user-triggered (manual) but hardened.
- Do NOT `git merge main` into `personal` (SortableImageGrid divergence — project memory).
- Conflict policy: desktop wins by origin (not wall-clock); clashes logged to sync_conflicts for an
  alert; mobile's losing value preserved.
